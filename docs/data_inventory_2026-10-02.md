## Proposal

1. Make `fire_event_dataset/` the library (one build, one set of IDs, one codebook). Do not start a new one.
2. Add modules that read the Experiment 6/7/8/10 tables above (read only; experiment folders stay as they are).
3. Master store: one DuckDB file written by the build, plus CSV/Parquet. Retire `aussef_duckdb/` (superseded) and
   keep `data/aussef.duckdb` as the frozen Experiment 1-4 archive (or move it to OneDrive).
4. Bowen's Excel is generated by the build. The Drive copy is replaced by the generated one, never hand-edited.
5. Before switching, diff the Drive workbook against a fresh build so no edits made directly in either copy are lost.
