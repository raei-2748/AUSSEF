# Stage-2 amendment 1 (2026-09-29, before any SL value was computed)
The DSS 2013/2014 CSVs suppress small cells as the text "<20" (e.g. Widow B Pension is "<20" in every council; Youth Allowance (other) in 28 of 153). The master rule "NaN if any component is non-numeric" would leave every council without a total. Decision from documentation (the suppression bound), fixed now: **a "<20" cell counts as 10** (midpoint of 0-19 rounded); the number of imputed cells per row is recorded and the SL cell is flagged `computed_low_confidence`. Everything else in PRESPEC_STAGE2.md 1.2 is unchanged. Only cell counts of "<20" (not any council value) had been looked at when this was written.
