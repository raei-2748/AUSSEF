# Fiscal forecasting diagnostics

Open `02_fiscal_prediction_diagnostics.ipynb` in the AUSSEF root and run top-to-bottom with AUSSEF as the working directory. Requires Python, NumPy, pandas, scikit-learn, matplotlib, IPython and Jupyter. Tested versions are in `diagnostic_manifest.json`.

Start with `diagnosis.md` and `research_verdict.md`. The notebook first reproduces all original predictions/metrics and stops on a discrepancy. `NSW Data Panel.csv`, `01_fiscal_decision_tree.ipynb` and all files in `outputs/decision_tree/` are verified by before/after hashes and never overwritten. `02_previous_diagnostics.ipynb` is the archived prior diagnostic; prior outputs in `outputs/decision_tree_diagnostics/` remain intact. The sole source dataset is the CSV; frozen derived outputs are only verification references.

Timing: t−1 fiscal/council predictors and t exposure predict t+1 operating ratio. Outer training outcome years are strictly before test exposure year t. Exact council_key/year joins, exclusions and complete-year tests match the original. Primary model comparisons use the same 370 held-out rows in three years. Secondary targets are reproduced and included in the temporal sample audit, not used to select the primary conclusion.

Models: training mean, persistence, fiscal-only and fiscal-plus-disaster depth-3 trees (minimum leaf 20), change tree, mean change, ridge level and ridge change. Ridge alpha grid is [0.1,1,10,100]. Imputation/scaling are fitted inside each training split. Inner validation is forward with the original embargo when feasible; otherwise it uses non-shuffled council-group folds within outer training data. This fallback is explicitly weaker evidence about temporal stability and never uses outer test outcomes. No feature search, ensemble or advanced ML is performed.

MAE/RMSE are percentage points. R² is out-of-sample and negative values are retained. Change versus reconstructed-level errors have equal MAE/RMSE but different R² references. Reusing previously inspected years makes these exploratory diagnostics, not independent confirmation.

Required files:
- `validation_model_comparison.csv`: pooled scores and annual wins against persistence.
- `year_by_year_validation.csv`: all eight models across all primary test years, with sample/exclusion counts.
- `prediction_errors.csv`: every held-out council-year, prior predictors, event quantities/statuses, predictions and errors.
- `largest_error_cases.csv`: 20 largest relative failures, 20 largest movements and 20 largest improvements (groups can overlap).
- `disaster_ablation_results.csv`: matched A/B split structure, prediction changes and metric gains.
- `change_prediction_results.csv`: change and reconstructed-level scores for all change baselines/models.
- `subgroup_error_summary.csv`: group counts, MAE/RMSE/bias, quartiles, median and p90, pooled and by year.
- `temporal_sample_audit.csv`: rows, councils and distinct temporal blocks for every original target/fold, including skipped years.
- `data_gap_priorities.md`: ranked data additions and availability constraints.
- `actual_vs_predicted.png`, `year_by_year_model_errors.png`, `paired_error_distributions.png`: visual diagnostics.

Additional audit files include frozen reproduction checks/hashes, ridge inner splits/scores and selected alpha, individual model predictions, tree nodes, subgroup deterioration rates, council/movement error summaries, and exact eligibility reasons. All generated files here except the prior-notebook archive may be regenerated by rerunning the notebook.

Verdict: NO-GO for escalating model complexity. Disaster-group comparisons are descriptive, not causal; missing exposure is not zero, and no declaration does not certify no physical exposure. Inspect underlying accounts before explaining large fiscal changes. Future outcomes or realised funding must never be repurposed as forecast-time predictors.
